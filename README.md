# LIM / NEON RUN

لعبة أركيد ثلاثية الأبعاد بطابع نيون مستقبلي، تعمل مباشرة في المتصفح دون تثبيت حزم.

## تشغيل اللعبة

- افتح [اللعبة مباشرة على GitHub Pages](https://seifjaballah77-eng.github.io/lim-system-project/) إذا كان GitHub Pages مفعّلًا للمستودع.
- أو افتح `index.html` محليًا في متصفح حديث مع اتصال بالإنترنت؛ تعتمد الرسوم ثلاثية الأبعاد على Three.js من CDN.

## طريقة اللعب

- **W A S D** أو **الأسهم:** التحرك داخل الساحة.
- **Space:** الاندفاع السريع.
- **Esc:** إيقاف مؤقت أو استئناف.
- اجمع البلورات الـ12 للحصول على النقاط والمكافأة، وتفادَ الحراس الحمراء.
- لديك 60 ثانية وثلاث وحدات طاقة. تُحفظ أفضل نتيجة محليًا في المتصفح.
- على الهاتف استخدم لوحة الاتجاهات وزر الاندفاع الظاهرين على الشاشة.

## الميزات

- ساحة 3D مبنية باستخدام Three.js، مع إضاءة نيون وظلال وعناصر متحركة.
- واجهة عربية RTL، ولوحة نقاط وطاقة ووقت ومهمة مباشرة.
- مؤثرات جسيمات وصوت اختياري، وأزرار لمس وتصميم متجاوب.
- شاشة بداية/نهاية، إيقاف مؤقت، وإعادة المحاولة.

## التحقق

يوجد سير عمل GitHub Actions في `.github/workflows/validate-game.yml` يفحص صياغة JavaScript المضمنة ويتحقق من وجود وظائف اللعب الأساسية عند الدفع إلى فرع `main`.

## النشر على GitHub Pages

من **Settings → Pages** اختر **Deploy from a branch** ثم فرع `main` والمجلد `/(root)`. بعد اكتمال النشر سيظهر رابط الموقع في إعدادات Pages. قد يستغرق ظهور التحديث بضع دقائق؛ جرّب تحديثًا قسريًا باستخدام `Ctrl+F5`.
